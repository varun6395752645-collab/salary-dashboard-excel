# Data Science Salary Dashboard 📊

An interactive **Excel Data Analytics Dashboard** for analyzing salaries and job-market information across data science and related roles.

## 📌 Project Overview

This project analyzes a dataset containing **32,000+ job postings** and presents the results through an interactive Excel dashboard.

The dashboard helps analyze:

* Job roles and job titles
* Median salaries
* Job locations and countries
* Work-from-home opportunities
* Employment/job schedule types
* Salary differences across job roles
* Job posting sources/platforms

## 📊 Dashboard

The main dashboard provides an interactive view of data science salary information and allows users to explore the data using filters and selections.

## 🗂️ Workbook Structure

### Data

Contains the raw job-posting dataset used for the analysis.

### Salary_Dashboard

The main interactive dashboard containing salary and job-market visualizations.

### Data Validation

Contains supporting data used for dropdowns, sorting, and dashboard selections.

### Jobs

Contains salary analysis based on different job roles.

### Country

Contains salary analysis based on country/location.

### Type

Contains salary analysis based on job schedule or employment type.

### Platform

Contains information related to job-posting platforms/sources.
